Documentation

OptiWatt permet à chacun de visualiser la consommation électrique de son compteur Linky sous forme de heatmaps (jour × heure), pour repérer d'un coup d'œil les talons de consommation, les pics et les habitudes.

1. Principe

L'application est un site statique hébergé sur GitHub Pages. Elle s'appuie sur Conso API (conso.boris.sh), un service gratuit qui relaie les API officielles d'Enedis, et propose deux façons de charger des données :

  • Par l'API : la courbe de charge (puissance par pas de 30 min) des 1 à 7 derniers jours, avec votre PRM et votre token ;
  • Par import d'un fichier CSV téléchargé depuis votre espace client Enedis, sans limite de durée.
Navigateur (GitHub Pages) ──► Proxy CORS (Cloudflare Worker) ──► conso.boris.sh ──► Enedis
        ▲
        └── import CSV (traité localement, rien n'est envoyé)

2. Obtenir son token

  1. Rendez-vous sur conso.boris.sh et cliquez sur le bouton d'accès à votre espace Enedis.
  2. Connectez-vous à votre compte Enedis et autorisez le partage de vos données (consommation, courbe de charge).
  3. Vous êtes redirigé vers une page qui affiche votre token (une longue chaîne de la forme xxx.yyy.zzz). Copiez-le.
  4. Votre PRM (ou PDL) est l'identifiant à 14 chiffres de votre compteur : il figure sur votre facture et dans votre espace client Enedis, et s'affiche sur l'écran du Linky (touche +).

La collecte de la courbe de charge doit être activée dans votre espace client Enedis (« Gérer l'accès à mes données »). Sans cela, l'API ne renvoie rien pour les mesures au pas de 30 minutes.

3. Onglet « Ma consommation »

Le résultat affiche trois indicateurs (période, énergie consommée, pic de puissance) et la heatmap. Les boutons PNG, SVG et Données CSV permettent d'exporter le graphique ou les mesures brutes, au même format que l'espace client Enedis : le fichier est donc réimportable dans l'onglet « Import ».

4. Onglet « Import d'un fichier Enedis »

  1. Dans votre espace client Enedis, ouvrez « Suivre mes mesures », choisissez la courbe de charge et la période voulue, puis téléchargez les données au format CSV.
  2. Importez le fichier dans OptiWatt. Le format attendu est celui d'Enedis : quelques lignes d'en-tête, puis une ligne Horodate;Valeur suivie des mesures (séparateur ; ou ,, horodatage ISO ou JJ/MM/AAAA hh:mm).
  3. Choisissez la vue :
    • Par mois : un petit graphique par mois (jours en abscisse, heures en ordonnée, 0 h en haut) ;
    • Long : une ligne par jour, la plus récente en haut.

Le bouton « Charger des données d'exemple » génère une année fictive pour tester l'outil sans compte Enedis.

5. Lire les heatmaps

  • Couleur : plus la case est foncée, plus la puissance appelée est forte. L'échelle va de 0 au plafond choisi.
  • Bande nocturne régulière (par ex. 1 h–4 h) : souvent le chauffe-eau asservi aux heures creuses.
  • Fond jamais clair : talon de consommation élevé (appareils en veille, réfrigérateur, VMC…).
  • Mois d'hiver plus foncés : part du chauffage électrique.
  • Cases au plafond : risque de dépassement de la puissance souscrite (disjonction).

Survolez ou touchez une case pour afficher le jour, l'heure et la valeur exacte.

6. Limites et bon usage

  • Quotas Enedis partagés par tous les utilisateurs de Conso API : 5 requêtes/s et 10 000 requêtes/h. Les abus peuvent entraîner un blocage d'IP.
  • Enedis ne met à jour les données qu'une fois par jour : une requête quotidienne suffit. OptiWatt garde les résultats en cache le temps de la session et ne rappelle pas l'API pour une même période.
  • La courbe de charge est limitée à 7 jours par requête. Pour un historique plus long, utilisez l'import CSV ou l'outil Python, qui découpe automatiquement la période.
  • Le plafond « kVA × 1000 » est une approximation : la puissance souscrite est apparente (VA), alors que la courbe de charge mesure une puissance active (W).

7. Confidentialité

  • Aucun serveur OptiWatt ne stocke vos données : les graphiques sont calculés dans votre navigateur.
  • Les fichiers CSV importés ne quittent pas votre appareil.
  • Lors d'un appel à l'API, le PRM et le token transitent par le proxy jusqu'à conso.boris.sh. Le proxy fourni ne journalise rien. Vous pouvez déployer le vôtre (§ 8).
  • Si vous cochez « Mémoriser », le token est conservé en clair dans le stockage local de votre navigateur. Ne l'activez pas sur un appareil partagé.

8. Le proxy CORS

Pour des raisons de sécurité, un navigateur n'autorise une page à appeler un autre domaine que si ce domaine l'accepte explicitement (en-têtes CORS). Comme conso.boris.sh n'envoie pas ces en-têtes, une page hébergée sur github.io ne peut pas l'appeler directement.

Le dossier proxy/ contient un Cloudflare Worker d'une cinquantaine de lignes qui :

  • n'accepte que les requêtes GET /api/<type> vers les types de données Conso API ;
  • relaie l'en-tête Authorization vers conso.boris.sh, avec un User-Agent identifiant OptiWatt, comme le recommande Conso API ;
  • ajoute les en-têtes CORS pour les seules origines autorisées (ALLOWED_ORIGINS) ;
  • ne stocke et ne journalise aucune donnée.
cd proxy
npm install -g wrangler        # une seule fois
wrangler login
wrangler deploy                # affiche l'URL https://optiwatt-proxy.<compte>.workers.dev

L'offre gratuite de Cloudflare Workers (100 000 requêtes/jour) est très largement suffisante.

9. Déployer sa propre instance

  1. Forkez le dépôt GitHub.
  2. Déployez le proxy (§ 8) et ajoutez l'URL de votre site (https://<user>.github.io) dans ALLOWED_ORIGINS (proxy/wrangler.toml).
  3. Dans Settings → Secrets and variables → Actions → Variables, créez la variable VITE_PROXY_URL avec l'URL du proxy.
  4. Dans Settings → Pages, choisissez « Source : GitHub Actions ».
  5. Chaque push sur main déclenche le workflow .github/workflows/deploy.yml, qui lance les tests, construit le site et le publie sur https://<user>.github.io/<repo>/.

10. Outil Python (CLI)

Le dossier python/ fournit le paquet optiwatt. Exécuté hors navigateur, il n'est pas concerné par le CORS : il récupère la courbe de charge sur une période longue, en la découpant en tranches de 7 jours espacées dans le temps, et produit un CSV directement importable dans l'application.

cd python
pip install -e .
export CONSO_TOKEN="xxx.yyy.zzz"
optiwatt fetch --prm 12345678901234 --start 2026-10-01 --end 2026-11-01 -o octobre.csv
optiwatt summary octobre.csv    # indicateurs dans le terminal

12. FAQ / dépannage

« Token invalide ou sans accès à ce PRM »
Le token a expiré ou correspond à un autre compteur : refaites le consentement sur conso.boris.sh.
« L'appel direct est bloqué (CORS) »
Aucun proxy n'est configuré : renseignez son URL dans les paramètres avancés.
« Aucune donnée sur cette période »
La collecte de la courbe de charge n'est pas activée, ou la période ne contient que la journée en cours.
Le CSV n'est pas reconnu
Vérifiez qu'il s'agit bien de la courbe de charge, et non des index ou des consommations journalières, et que le fichier contient une colonne « Horodate ».
