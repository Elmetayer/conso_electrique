Paramètres avancés

Pré-rempli avec le relais officiel. Vous pouvez indiquer votre propre relais (voir la documentation). Laisser vide pour appeler conso.boris.sh directement (bloqué par les navigateurs).

Bon usage de l'API — Enedis ne met à jour les données qu'une fois par jour et le quota est partagé par tous les utilisateurs de conso.boris.sh. Une requête par jour suffit : les résultats sont gardés en cache (12 h sur le relais, et pendant la session dans votre navigateur). La courbe de charge est limitée à 7 jours par appel.
Données : Conso API / Enedis. Vos données restent dans votre navigateur.
